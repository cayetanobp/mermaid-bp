# Plugins

Para instalar un plugin, copia su carpeta aquí y recarga la web. Aparecerá en "Extensiones". Para quitarlo, retira su carpeta y recarga.

El núcleo no incluye plugins. Las carpetas que se añadan aquí se empaquetan como extensiones instalables; cada plugin debe documentar su propia licencia y conservar los avisos de terceros que le correspondan.

Cada carpeta contiene `plugin.json`, `index.js` y los recursos que necesite. No hay que editar registros ni recompilar.

La guía para crearlos está en [docs/plugins.md](../docs/plugins.md).
