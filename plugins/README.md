# Plugins

Para instalar un plugin, copia su carpeta aquí y recarga la web. Aparecerá en "Extensiones". Para quitarlo, retira su carpeta y recarga.

El plugin propio de BookStack se distribuye bajo GNU AGPL-3.0-only, con el texto y los avisos del proyecto. Los plugins de terceros conservan sus respectivas licencias.

Cada carpeta contiene `plugin.json`, `index.js` y los recursos que necesite. No hay que editar registros ni recompilar.

La guía para crearlos está en [docs/plugins.md](../docs/plugins.md). BookStack está incluido en `bookstack/`.
